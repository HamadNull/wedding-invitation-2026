إدارة الدعوة والتذاكر

مهم قبل استخدام الدعوة فعلياً

هذه النسخة واجهة ثابتة مناسبة للنشر التجريبي على GitHub Pages. إصدار QR يتم داخل متصفح الضيف، لذلك لا توجد قاعدة بيانات مركزية ولا يمكن منع التذاكر المكررة أو التحقق من استخدامها مرة واحدة على عدة أجهزة.

لتشغيل نظام دخول حقيقي

  1. أنشئ مشروع Firebase.
  2. فعّل Cloud Firestore وAuthentication.
  3. انقل إصدار التذاكر إلى وظيفة موثوقة في الخادم، وأنشئ معرفاً فريداً لكل تذكرة.
  4. اجعل صفحة المنظم تتطلب تسجيل دخول، وتتحقق من التذكرة ثم تسجل check-in بمعاملة ذرية (transaction).
  5. لا تضع مفاتيح خدمة خاصة أو صلاحيات إدارية داخل ملفات الواجهة العامة.

الإعدادات التي يجب تعديلها

افتح index.html وابحث عن const CONFIG ثم عدّل أسماء العروسين والتاريخ والقاعة ورابط الخرائط ورقم واتساب.

صيغة رقم واتساب: رمز الدولة ثم الرقم دون + أو مسافات، مثال شكلي للعراق: 9647XXXXXXXXX.

النشر على GitHub Pages

  1. ارفع index.html وملف README.md إلى مستودع GitHub.
  2. من Settings ثم Pages اختر النشر من فرع main ومجلد /(root).
  3. افتح الرابط الناتج واختبره من هاتفك.
