# دعوة زفاف إلكترونية

واجهة عربية RTL لدعوة زفاف، تتضمن:
- تصميم متجاوب بألوان داكنة وذهبية.
- شاشة فتح الدعوة وعدّاد تنازلي.
- معلومات القاعة ورابط خرائط Google.
- إضافة الموعد إلى Google Calendar.
- نموذج تأكيد حضور وبيانات المرافقين.
- إنشاء QR للتذكرة وتنزيل البطاقة كصورة PNG.
- فتح WhatsApp برسالة جاهزة.
- رابط ضيف مخصص عبر `?guest=اسم%20الضيف`.

## تشغيل سريع
افتح `index.html` محلياً أو ارفعه إلى GitHub Pages.

## تخصيص البيانات
داخل `index.html` ابحث عن `const CONFIG` وعدّل:
- `groom`, `bride`
- `dateISO` بصيغة ISO 8601 مع المنطقة الزمنية
- `dateLabel`, `venue`, `mapsUrl`
- `organizerWhatsApp` بصيغة دولية دون علامة `+`
- `eventId`

## تنبيه أمني وتشغيلي
هذه النسخة **واجهة تجريبية ثابتة**. بيانات RSVP لا تُحفظ في قاعدة بيانات، ومعرّف QR ينشأ في متصفح الضيف. لذلك لا تصلح وحدها لإدارة دخول حقيقي أو لمنع إعادة استخدام التذاكر. رابط WhatsApp يجهز الرسالة فقط، ولا يرسلها دون تأكيد المستخدم. إرسال صورة التذكرة تلقائياً يتطلب خادماً وتكاملاً مع WhatsApp Business Platform أو مزود معتمد.

لتحويلها إلى نظام إنتاجي، أضف Backend وقاعدة بيانات وتسجيل دخول للمنظم. يجب أن يصدر الخادم التذكرة ويتحقق من QR ويسجل الدخول بشكل ذري لمنع استخدام التذكرة مرتين.
